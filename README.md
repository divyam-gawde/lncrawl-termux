# lncrawl-termux

Run **Lightnovel Crawler (lncrawl)** on Android using **Termux + Ubuntu 24.04**.

This project provides a simple automated installer for ARM64 Android devices. It installs the required Linux environment, Python dependencies, Lightnovel Crawler, and starts the lncrawl web server.

## 🚀 One-Command Installation

Open a fresh Termux session and paste:

```bash
curl -fsSL https://raw.githubusercontent.com/divyam-gawde/lncrawl-termux/main/install.sh | bash
